Um time de IA no seu repositório. A decisão final é sua.

AgentSpace roda Missions em worktrees git isolados e mostra o diff e as evidências. Nada chega à main sem você.

Você descreve. O time executa. Você decide.

Não é um chat nem um quadro de tickets. É uma superfície de supervisão: você sai, e volta para resultados prontos para decidir.

  1. Conectar

    Aponte uma pasta local ou um remoto. A branch padrão é detectada e tratada como protegida.

  2. Descrever

    Escreva o pedido e, se quiser, os critérios de aceite. Escolha quais papéis participam.

  3. Executar

    Planner, Developer, QA e Reviewer rodam em sequência no mesmo worktree, com evidências ao vivo por papel.

  4. Decidir

    Diff, build antes e depois e revisões no mesmo lugar. Allow faz rebase e push. O PR é seu.

Decisões técnicas que importam

Como o projeto evita que um time autônomo vire um risco para o seu repositório e para a sua máquina.

Nunca faz merge
Allow faz rebase da branch da Mission sobre a base e push com --force-with-lease para o origin, usando as credenciais git que você já tem. O PR é manual.
Um worktree por Mission
Cada Mission trabalha numa branch legível, derivada do pedido, isolada da sua pasta de trabalho. Várias rodam em paralelo, com limite configurável.
Build verificado na base e no resultado
O comando de build e teste roda nos dois commits. Assim dá para separar "esta Mission quebrou" de "já estava quebrado".
Guarda de segredos
Arquivos como .env, chaves .pem e id_rsa ficam fora do commit da Mission e são sinalizados na tela de aprovação.
Servidor só local
A API executa git e shell, então escuta apenas em 127.0.0.1 e recusa Host ou Origin que não sejam loopback, o que bloqueia sites externos e DNS rebinding.
Provedor isolado atrás de um adaptador
Só uma camada conhece o Claude Code. O resto fala com uma interface, e um provedor simulado permite desenvolver sem chamadas reais. Trabalho simulado nunca pode ser aprovado.

Stack: Node.js 22+ com node:sqlite, Express, SSE para atualização ao vivo, React 18, TypeScript, Vite e Tailwind v4.

Como rodar localmente

Não há versão hospedada: o app executa git e shell na sua máquina. Requer Node.js 22.13+ e git. Para Missions reais, o CLI do Claude Code instalado e autenticado.

Por padrão o provedor é simulado, sem chamadas de IA. Para o time real, defina AGENTSPACE_PROVIDER=claude-code no .env.
