# AgentSpace — web

The React frontend of AgentSpace (Vite + TypeScript + Tailwind v4 + shadcn/ui, dark-only). See the [root README](../README.md) for features, screenshots and how to run everything.

```bash
npm run dev      # Vite on :5173, proxies /api to the Express server on 127.0.0.1:4310
npm run build    # builds into ../dist-web, which Express serves on :4310
npm run lint
```
